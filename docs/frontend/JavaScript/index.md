# JavaScript 零基础教程

本课程面向已经完成 HTML 和 CSS 基础的学员。先学习 JavaScript 的值、数据结构和函数，再操作浏览器页面，最后学习模块、异步与网络请求。

完成课程后，你应能使用 JavaScript 处理表单、页面状态和浏览器存储，并看懂前端项目中常见的模块与请求代码。课程结束时完成[有給休暇申請システム综合练习](../../exercises/frontend/JavaScript/24_js_project.md)。

具体来说，你将能够在 HTML 页面中加载脚本，使用变量、数组、对象和函数组织业务数据；通过 DOM 和事件处理按钮、表单与页面更新；完成注册、登录、申请、确认、筛选和取消等前端交互；使用浏览器存储保存练习数据，并借助开发者工具排查常见错误。这些能力也为后续 TypeScript、Vue 和 React 学习打下基础。

## 学习要求

- **必须掌握**：变量、类型、条件、循环、数组、字符串、函数、对象、DOM、事件、表单校验、JSON、浏览器存储和错误处理。
- **需要掌握**：解构、展开、可选链、正则、日期处理、ES 模块、Promise、`async`/`await`、`fetch`、Axios、`Set` 和 `Map`。
- **了解即可**：复杂闭包和递归技巧、原型链细节、`WeakSet`、`WeakMap`、`Symbol`、`Proxy`、`Reflect`、Babel 与 Webpack。
