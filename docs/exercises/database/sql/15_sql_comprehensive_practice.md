# 第15章 SQL 综合练习

## 1-1 创建学生选课数据

请在独立的练习数据库或 Schema 中创建 `Student`、`Teacher`、`Course`、`SC` 四张表，并录入本节指定的数据。选择当前使用的数据库产品（MySQL、Oracle、PostgreSQL 或 SQL Server），自行编写对应的建表和插入语句。

### 任务一：创建表

`Student` 保存学生资料。

| 字段 | 要求 |
| --- | --- |
| `SPlus` | 学生编号，最多 10 个字符，主键 |
| `Sname` | 学生姓名，最多 10 个字符，非空 |
| `Sage` | 出生日期时间；表中只列出日期，录入时使用当天 `00:00:00` |
| `Ssex` | 性别，最多 2 个字符 |

`Teacher` 保存教师资料。

| 字段 | 要求 |
| --- | --- |
| `TPlus` | 教师编号，最多 10 个字符，主键 |
| `Tname` | 教师姓名，最多 10 个字符，非空 |

`Course` 保存课程和任课教师。

| 字段 | 要求 |
| --- | --- |
| `CPlus` | 课程编号，最多 10 个字符，主键 |
| `Cname` | 课程名称，最多 10 个字符，非空 |
| `TPlus` | 教师编号，最多 10 个字符，外键引用 `Teacher.TPlus` |

`SC` 保存学生的选课成绩。表名沿用本练习提供的名称。

| 字段 | 要求 |
| --- | --- |
| `id` | 自增主键，由数据库生成 |
| `SPlus` | 学生编号，最多 10 个字符，外键引用 `Student.SPlus` |
| `CPlus` | 课程编号，最多 10 个字符，外键引用 `Course.CPlus` |
| `score` | 成绩，保留 1 位小数，不得大于 100 |

`01`、`02` 等编号的前导零属于数据的一部分，建表和录入后都必须保留。`SC` 的数据只给出 `SPlus`、`CPlus` 和 `score`，不要把第一列误认为自增的 `id`。

## 1-2 学生选课数据查询

使用 `1-1` 中创建的四张表和指定数据，完成下面 50 道查询。每题自行编写 SQL，并保存查询结果；不要修改原始数据来迎合题目。编号如 `01`、`02` 均按原样匹配。

本节统一约定：

- “所有学生”包括没有选课记录的学生；需要显示汇总值时，明确区分没有成绩与成绩为 `0`。
- 第 18 题的及格率为成绩 `>= 60` 的比例；中等为 `70 <= score < 80`，优良为 `80 <= score < 90`，优秀为 `score >= 90`。比例以该课程的选课记录数为分母。
- 第 22 题的分数段互不重叠：`85 <= score <= 100`、`70 <= score < 85`、`60 <= score < 70`、`0 <= score < 60`。各段百分比以该课程的选课记录数为分母。
- 第 46～50 题以执行查询当天为基准；一周从周一开始、到周日结束。生日只比较月和日，不比较出生年份。

1. 查询 `01` 课程比 `02` 课程成绩高的学生信息，以及这两门课程的分数。
2. 查询 `01` 课程比 `02` 课程成绩低的学生信息，以及这两门课程的分数。
3. 查询平均成绩大于等于 60 分的学生编号、姓名和平均成绩。
4. 查询平均成绩小于 60 分的学生编号、姓名和平均成绩。
5. 查询所有学生的编号、姓名、选课总数和所有课程的总成绩。
6. 查询姓“李”的教师人数。
7. 查询学过“张三”老师授课的学生信息。
8. 查询没有学过“张三”老师授课的学生信息。
9. 查询既学过 `01` 课程、也学过 `02` 课程的学生信息。
10. 查询学过 `01` 课程、但没有学过 `02` 课程的学生信息。
