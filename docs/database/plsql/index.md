## 运行说明

PL/SQL 依赖 Oracle 数据库。本站展示教材与流程示意，不会使用浏览器内 SQLite 来冒充 Oracle 或执行 PL/SQL。需要运行代码时，请按第 1 章准备个人练习环境，并在数据库客户端核对输出和数据变化。
