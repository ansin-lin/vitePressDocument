# 课程目录

## Web 开发基础

[HTML 基础教程](../frontend/HTML/index.md)从网页结构与常用元素开始。

[CSS 基础教程](../frontend/CSS/index.md)学习样式、布局与响应式页面。

[JavaScript 基础教程](../frontend/JavaScript/index.md)学习程序逻辑、DOM 交互、浏览器存储和异步请求。部分章节可以在线修改并运行代码。

[Node.js 与 npm 基础](../frontend/NodeJS/index.md) 学习前端项目使用的运行环境、依赖管理和脚本命令，建议在 TypeScript、Vue、React 之前完成。

[TypeScript 基础教程](../frontend/TypeScript/index.md)从类型标注学到泛型、模块和业务数据建模，并通过结课练习检查外部数据。

[Vue 3 教程](../frontend/Vue/index.md)从单文件组件、响应式状态和组件通信，学到路由、接口、状态管理与测试。

[React 教程](../frontend/React/index.md)从 JSX、Props 和 State，学到业务页面、请求、路由、状态管理与测试。

## Java

[Java 基础教程](../backend/java/index.md)从第 1 章入门，依次覆盖语法、面向对象、集合、文件、Maven、JDBC 和 JUnit。进入课程后可用左侧目录切换章节。

[MyBatis 教程](../backend/mybatis/index.md) 在 Java、Maven 和 SQL 之后学习 Mapper、SQL 映射、动态 SQL 与执行流程。

[Spring Boot 教程](../backend/springboot/index.md) 在 Java、HTTP、SQL 和 MyBatis 基础之后学习员工管理后端 API；附录与企业扩展可按需阅读。

## 数据库

[SQL 知识课程](../database/sql/index.md)从数据库基本概念开始，逐步进入数据操作、查询与视图。进入课程后可用左侧目录切换章节。
